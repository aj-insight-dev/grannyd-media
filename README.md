# grannyd-media

Images for [grannydsolutions.com](https://www.grannydsolutions.com), served by GitHub Pages at
`https://aj-insight-dev.github.io/grannyd-media/<file name>`.

The site itself is one Squarespace Code Block made from the `grannydsolutions` repo (`dist/console.paste.html`). Nothing in this repo runs on the site except these images.

**This repo is public.** Only reviewed images and this README belong here: no client details, records, passwords or keys.

Don't rename a file: the site finds each one by its exact name. To change a photo, upload a new file with the **same name**. No code change is needed.

## Latest change: Update 1, first upload (2026-10-11)

The black and gold console (site v2.0.0). Seven images, all WebP, made from the `Images` folder in grannyd-site.

To apply it: upload the seven files and this README to the repo root, turn on GitHub Pages (below), then paste `dist/console.paste.html` into Squarespace.
